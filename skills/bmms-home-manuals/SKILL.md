# 全屋说明书

本 Skill 属于 bmmskill 系列。

## 它解决什么

问 AI "我家这台怎么用""它为什么坏"，普通聊天没有真源，容易编；型号差一个字母，功能和接口就不一样。本 Skill 让 Agent 先把你家每台电器的官方说明书按精确型号收进项目目录，之后回答先查说明书、引页码。说明书没写的，明说是推测，给排除顺序，不装成说明书写的。

## 三条硬规则

1. **清单是人写的真源。** `家电清单.md` 的品牌、型号、产品名、放在哪四列只由用户填，Agent 不替用户猜型号、不改这四列。型号以机身铭牌为准，不以购买记录或记忆为准。"说明书"和"备注"两列是状态列，Agent 找完后更新，更新时告诉用户改了什么。
2. **型号严格匹配。** 一个字母、一个后缀都不能差。找不到精确型号就报"没找到"，不拿相近型号充数，转而请用户拍铭牌或纸质说明书。拍照版进库时标"用户上传"，可信度低于官方。
3. **回答分两档，开头先标档位。** 档一，说明书写了：引"哪份文件、第几页或哪一节"，不加说明书没有的内容。档二，说明书没写：第一句就说"说明书没写这个，下面是推测"，然后进诊断流程。两档不混。

## 第一次开口

**安装完成的那个会话里，Agent 读到本文件就立即执行本节，不等用户再说一句。**之后任何时候清单文件不存在或为空，也执行本节。Agent 主动说这两句（文案为作者原话，可按 Agent 语气微调，意思不变）：

> 现在有什么家电想让我记录？

用户说没有、或不知道从哪说起：

> 要不要我说一个、你答一个？你家的冰箱是什么型号？

之后按冰箱、洗衣机、空调、热水器、灯具、小家电的顺序一问一答。**每答一台，立刻去找这台的说明书，当场回一句**："找到了，官方版，存在 `家电支持中心/<品牌_型号>/`，这台可以问我了"，或"没找到精确型号，拍一下机身铭牌或纸质说明书给我"。不攒到最后一起找。用户说"先这些"就停，不追问。

## 目录

```text
<项目目录>/家电支持中心/
  家电清单.md                 用户维护，模板见 references/01_清单模板.md
  <品牌_型号>/
    说明书.pdf               官方下载版；拍照版放 说明书_用户拍照/ 子目录
    来源.md                  下载自哪、日期、官方还是第三方还是用户上传
    这台的坑.md              说明书之外的真源：踩过的问题、真正原因、怎么解的。用户确认后才写
```

`<品牌_型号>` 用铭牌上的写法，不翻译、不简写。

## 流程

### 步骤 1 · 录清单

读 `家电清单.md`。没有就按"第一次开口"引导建立。每台一行：品牌、型号、放在哪、备注。型号用户没把握时，告诉他铭牌通常在哪（见 references/02）。

### 步骤 2 · 找说明书

按 references/02 的五级真源优先级找：官网托管、厂商原稿托管在别处、第三方说明书站、用户拍照、近似型号。到达方式按 Agent 有没有浏览器分两条路，目标都是先拿第 1 级。下载后存进该台目录，写 `来源.md`。核对方式是全文搜清单里的型号字符串：封面、规格段、合规声明、适用型号表，任一处出现即算一致；全文没有就按没找到处理。核完型号再看语言和地区版本，见 references/02；只找到外文版或国际版而预算没用完，再搜一次中文版，还是没有就入库并告知用户。然后把清单"说明书"一列更新成对应状态。

### 步骤 3 · 问答

用户问某台怎么用或出了什么问题时：

1. 从清单确认是哪一台；用户没说型号而家里有多台同类，先问是哪台。
2. 读这台的说明书，找直接对应的章节。
3. 有：按档一回答，引 PDF 页码或章节名；说明书是整张拼版、PDF 页码和印刷页码不一致时两个都写。用户要原文就贴原文。
4. 没有：按档二回答，模板见 references/03。先复述型号和现象，列出可能原因，按概率给排除顺序，每一步说清让用户做什么、观察什么，全程标明是推测。
5. 两档都要先查 `这台的坑.md`，里面有记录的优先引用。

### 步骤 4 · 记坑

档二走完、问题解决后，问一句"要不要把真正原因和解法记进这台的坑"。用户确认才写，写用户的话，不写 Agent 的推理过程。

## 边界

- Agent 不碰电器、不读设备内部数据，做的是读说明书和排除顺序。涉及拆机、电路、燃气的，只引说明书的安全章节，其余建议找售后。
- 不推荐买什么、不比价、不给购买链接。用户问"要不要换新"只按本台说明书和现象回答。
- 健康类设备只讲用法，不记录也不分析身体数据。
- 第三方说明书站的文件仅供个人非商业使用，不转发、不打包分享。
- 品牌和型号只用于找说明书，不作任何评价。

## 哪类 Agent 跑得了

需要三样能力：联网搜索并下载文件、读 PDF、在项目目录里存文件。Codex、Claude Code、WorkBuddy 的 Craft 模式可以。只能聊天不能存文件的网页版用不了本 Skill，它会在下一次对话忘掉你家有什么。

不强制要浏览器。官网优先这条不变，到达方式按能力分两条（见 references/02"怎么到达"）：有浏览器的进官网支持页按型号搜；没有的用搜索引擎先限定官方域名搜，再放开搜。
