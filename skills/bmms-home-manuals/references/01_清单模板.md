# 家电清单.md 模板

品牌、型号、放在哪三列由用户维护，Agent 不改；用户口述时由 Agent 代笔，但每一行录入前把品牌和型号念回给用户确认。"说明书"一列由 Agent 在找完后更新，更新时告诉用户。

```markdown
# 家电清单

更新：YYYY-MM-DD

| 品牌 | 型号（按铭牌） | 放在哪 | 说明书 | 备注 |
|---|---|---|---|---|
| 某品牌 | XX-123A | 厨房 | 官方 2026-01-05 | |
| 某品牌 | YY-9 | 卧室 | 用户拍照 | 官网没找到精确型号 |
| 某品牌 | ZZ-77 | 书桌 | 未找到 | 待拍铭牌 |
```

- "说明书"一列由 Agent 维护，五种值：官方＋日期、官方文件托管于第三方＋日期、第三方＋日期、用户拍照、未找到。外文版或国际版在值后面加括号注明，如"官方 2026-01-05（国际版，无中文）"。
- 同品牌同类多台（两盏灯、两台空调）分两行，型号哪怕一样也分两行，"放在哪"区分。
- 型号里的横杠、斜杠、空格照铭牌抄，不规整。
